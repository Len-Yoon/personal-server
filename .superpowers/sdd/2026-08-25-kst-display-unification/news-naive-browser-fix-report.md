| 항목 | 내용 |

| 작업 범위 | 뉴스 자동 새로고침의 시간대 없는 ISO 8601 시각 브라우저 표시 |
| 제외 범위 | Python 포매터, 기사 저장·정렬, 서버 기동, 스케줄러 |

| 목적 | 서버의 naive ISO UTC 해석과 자동 새로고침 화면의 KST 표시를 일치시킴 |

## 2. 핵심 요약

- 시간대 정보가 없는 ISO 8601 시각은 브라우저 로컬 시간이 아닌 UTC로 해석하도록 `Z`를 보완함.
- 실제 Node 렌더링 테스트에서 호스트 시간대를 `America/New_York`으로 설정하고 `2026-07-09T01:02:03` 입력이 `2026-07-09 10:02`로 표시됨을 검증함.
- 기존 timezone 포함 ISO 및 RFC 822 UTC 입력 회귀는 유지함.
