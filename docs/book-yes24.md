## 상세 내용

### 키 발급과 등록

1. [YES24 Developers](https://developers.yes24.com/)에서 YES24 계정으로 로그인함.
2. `API Key 신청하기`에서 개인 독서 기록용 검색·목차 활용 목적을 기재하고 약관에 동의함. 공식 안내상 신청 즉시 키 발급됨.
3. 서버 설정 이름은 `YES24_API_KEY`임. 키 값은 채팅·소스·Git·로그에 남기지 않음. 로컬 Compose는 기존 루트 `.env` 로딩, 운영 K3s는 기존 `book-memo-runtime` Secret의 승인된 등록 절차를 사용함. 실제 값·등록 명령은 문서에 저장하지 않음.
4. 운영 Secret 등록·이미지 반입·Book Pod 교체는 검증된 대상·커밋·순서를 준비한 뒤 별도 운영 승인으로 수행함. 키 발급만으로 운영 연동이 완료되지는 않음.

### 입력·표시·오류·저장 경계

| 경계 | 처리 | 비고 |
|---|---|---|
| 검색 입력 | 공백 제거, 최대500자·결과40건, 전체3초/제공자1초 제한 | 기존 DNS·느린 본문 취소 유지 |

| 응답 | success/errorCode/data/items 검증, ISBN13 우선, ISBN 없는 유효 상품은 yes24:상품번호 식별자 사용 | 실제 ISBN을 임의 생성하지 않음. 2MiB 제한, 키 지문별 캐시 TTL60초·최대128건 |

## 검토 결과

| 항목 | 결과 | 비고 |
|---|---|---|
| 역할 | 주 담당 구현·자기 검증, Sol high 전문·독립 검토 | 실제 작성자는 최종 검토 제외 |
| 자동배포 | 운영 신뢰 helper 조회에서 book-memo=k3s 확인 | k3s_runtime_service 배포 제외 유지 |
| 검증 | 검색·목차·인증·오류·캐시·실제 loopback HTTP 회귀 추가 | 최종 실행 결과·커밋은 PR에 고정 |
| 실제 YES24 검색 | 손자병법12건 0.322초, 클린 코드12건 0.254초, ISBN1건 0.163초 | 키체인 키→메모리 사용, 실제 제품 검색 함수 결과. 운영 Pod 결과 아님 |
| 실제 YES24 목차 | 손자병법 첫 결과의 후보120개·출처 링크 확인, 0.153초 | 120개는 기존 후보 상한임. 운영 저장 안 함 |

맥 Python의 기본 CA 경로 부재로 최초 TLS 검증 실패 후 프로젝트 certifi 묶음을 지정해 검증함. TLS 검증을 끄지 않았으며 실제 배포 이미지의 기본 CA로 실제 검색·목차 요청도 성공함.

## 목차 미리보기 후속 보완

사용자 선택에 따라 미리보기→원하는 항목 선택→저장 흐름을 유지함. 미리보기만으로 책·목차가 저장되지 않으며, 기존 책의 목차·메모도 바꾸지 않음.

| 경계 | 보완 내용 | 비고 |
|---|---|---|
| 긴 목차 | 기존120개에서 최대500개 후보까지 표시 | 실제 클린 코드332후보 확인. 501번째 유효 항목이 있으면 부분 표시 안내 |
| 선택 | 검색·상세 양쪽에 선택/전체 개수 표시 | 전체 선택·해제·대/중목록 선택 유지 |
| 재조회 | 같은 항목의 선택 상태 유지, 실패 시 기존 후보 보존 | 오류를 목차 없음과 구분 |
| 로그인 복원 | 복원된 후보에도 선택 컨트롤·개수 표시 | 재조회해도 같은 항목의 선택·해제 유지 |
| 저장 | 선택한 목차만 기존 저장 경로로 추가 | 미리보기 무저장·중복 제거·기존 메모 보존 회귀 검사 |
| 운영 범위 | 이 후속 코드의 N100 추가 적용은 미수행 | 아래 초기 YES24 배포 결과와 구분 |

주 담당의 구현·자기 검증과 작성 미참여 Sol high의 독립 검토를 구분함. 실제 템플릿과 초안 JavaScript를 함께 실행한 선택/실패/복원 검사, 가짜 API·격리 DB의 HTTP 선택 저장 검사, 긴 응답·부분 표시 회귀를 수행하며 최종 결과는 해당 PR에 고정함.

## 확인 필요 사항

- [이용약관](https://developers.yes24.com/support/terms)은 출처·상품 링크와 캐싱 범위, 데이터 축적·재배포 제한을 규정함. 선택한 책·목차의 개인 장기 저장과 기존 JSON/Markdown 내보내기의 허용 범위는 YES24에 확인 필요함. 코드 변경을 이용 허가 확인으로 확대하지 않음.
- ISBN 없는 상품을 저장한 뒤 제공자가 ISBN을 추가하면 기존 ISBN 고유키 기준으로 별도 책이 생길 수 있음. 자동 추정 병합은 하지 않으며 해당 변경 시 중복 여부 확인 필요함.
