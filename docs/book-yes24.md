## 상세 내용

### 키 발급과 등록

1. [YES24 Developers](https://developers.yes24.com/)에서 YES24 계정으로 로그인함.
2. `API Key 신청하기`에서 개인 독서 기록용 검색·목차 활용 목적을 기재하고 약관에 동의함. 공식 안내상 신청 즉시 키 발급됨.
3. 서버 설정 이름은 `YES24_API_KEY`임. 키 값은 채팅·소스·Git·로그에 남기지 않음. 로컬 Compose는 기존 루트 `.env` 로딩, 운영 K3s는 기존 `book-memo-runtime` Secret의 승인된 등록 절차를 사용함. 실제 값·등록 명령은 문서에 저장하지 않음.
4. 운영 Secret 등록·이미지 반입·Book Pod 교체는 검증된 대상·커밋·순서를 준비한 뒤 별도 운영 승인으로 수행함. 키 발급만으로 운영 연동이 완료되지는 않음.

### 입력·표시·오류·저장 경계

| 경계 | 처리 | 비고 |
|---|---|---|
| 검색 입력 | 공백 제거, 최대500자·결과40건, 전체3초/제공자1초 제한 | 기존 DNS·느린 본문 취소 유지 |
| 인증 | 고정 HTTPS 호스트에 X-Api-Key 헤더 전송 | 프록시 환경·리다이렉트 비활성 |
| 응답 | success/errorCode/data/items 검증, ISBN13 우선 | 2MiB 제한, 키 지문별 캐시 TTL60초·최대128건 |
| 정상0건 | 성공 빈 items 또는 404 SEARCH_001 | SEARCH_002·인증·429와 구분 |
| 검색 장애 | 보조 검색도 결과가 없으면 YES24 오류 표시 | 실패 빈 결과 캐싱 안 함 |
| 목차 | YES24 상품번호 또는 기존 ISBN13 사용, 유효 ISBN10은 13자리로 변환 | 제목으로 추정 매칭 금지 |
| 목차 없음 | 404 GOODS_001/GOODS_002는 빈 후보 | 다른 실패는 안전한 HTTP503 JSON |
| 표시 | YES24 출처·canonical 상품 링크와 표지 CSP 호스트 | 기존 이미지·크기·비율·배치 보존 |
| 저장 | 기존 ISBN 고유키와 저장 경로 사용 | 기존 조회·내보내기 계약 유지 |
| 제외 | Secret/PVC/운영 데이터·Caddy/Tunnel·일정·배포 정책·V2 | 변경 안 함 |

| 실제 YES24 검색 | 확인 필요 | 실키 미등록으로 손자병법·ISBN·목차 응답 미검증 |

## 확인 필요 사항

- [이용약관](https://developers.yes24.com/support/terms)은 출처·상품 링크와 캐싱 범위, 데이터 축적·재배포 제한을 규정함. 선택한 책·목차의 개인 장기 저장과 기존 JSON/Markdown 내보내기의 허용 범위는 YES24에 확인 필요함. 코드 변경을 이용 허가 확인으로 확대하지 않음.
- 실키로 대표 검색어·ISBN을 확인한 뒤 응답시간에 맞춰 제한 조정 필요 여부를 판단함. 합성 성공을 실제 제공자 정상 응답으로 표현하지 않음.
