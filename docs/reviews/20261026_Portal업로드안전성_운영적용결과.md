### 3.1. 검증 경로 보완

맥 Docker의 image inspect2회·info1회가 시간 초과되어 후보 이미지78회귀는 시작되지 않음. 시험 컨테이너가 생성되지 않았고 V2 영향 방지를 위해 daemon을 재시작하지 않음. 이를 이미지 실행 검증 성공으로 기록하지 않음.

대신 새 Portal Pod에서 별도 Python 자식에 PATH·개발 모드·임시 경로만 전달하고, PVC/hostPath가 아닌 `/tmp`의 전용 TemporaryDirectory에서 실제 이미지 코드를 검사함. 파일함·감사 로그·인증 상태를 모두 해당 임시 경로로 지정함. Git 원본 테스트3파일은 개별 SHA를 검사한 뒤 복원하고 실제 `/app`을 참조함. 내장 fixture 자체 SHA도 설정과 대조한 뒤에만 자식을 실행함. 운영 서버 프로세스의 환경·데이터를 변경하지 않으며, 기존/원복 Pod에는 새 회귀를 실행하지 않음. 회귀 실패는 기존 단일 원복 보호 경계에 포함됨.

사전 검토에서 내장 fixture 지문과 설정의 연결 누락을 발견하여 실행 전에 보완함. 먼저 전송한 구버전 절차·설정은 실행하지 않았고, 미시작·소유·기존 SHA를 확인한 뒤 조건부 교체함. 최종 원격 절차 SHA256은 `104dbd0a24c7c261f713a2368327b67021ce85cdce86b25a451449964c1aa7e9`이며 전송 manifest·실행 PID 기록과 일치함.

## 5. 확인 필요 사항

- 실제 사용자 파일/PVC 내용의 byte 동등성, 운영 파일함 쓰기 시험, Secret 값 비교는 미수행임. PVC 식별자·설정 보존과 격리 시험으로 구분함.
- Recreate 단일 Pod 교체이며 연속 무중단·장기 가용성·향후 백업 성공을 입증하지 않음.
- 맥 Docker API 응답 문제는 미해결임. 이번 작업에서 로컬 runtime/V2를 재시작하거나 재설정하지 않음.
- 정상 상태 정리 산출물은 에이전트 관측이며 사용자 직접 실습 완료를 뜻하지 않음.

## 6. 후속 조치

종료·소유·단일 링크·허용 목록·SHA를 확인하여 원격 임시 폴더1개·파일10개만 정리하고 정리 후 외부 health200을 추가 확인함. 기존·신규 containerd 이미지를 보존하며 로컬 OCI와 비민감 검증 원본은 운영 근거로 유지함. [정상 상태 점검표](../20261026_V1_정상상태점검.md)를 기준으로 다음 읽기 점검을 이어감. 이번 배포 승인은 완료·소진됐으며 새 운영 변경에 재사용하지 않음.
