## 2. 핵심 요약

실제 다른 Book 앱 코드 두 개를 현재 동일 빌드 환경에서 빌드함. 업그레이드·역방향 읽기/쓰기·readiness 실패 롤백을 각3회, 총9회 통과함. 관련8테이블 논리 snapshot·schema hash·기존 자료·요청 원장·integrity와 컨테이너 내부 HTTP를 대조함. 사용자의 수동 진단·운영 배포·무중단 성공과 구분함.
