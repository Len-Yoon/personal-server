## 검토 결과

- 주 에이전트: 실제 운영 상태 확인, 빌드·반입·교체·최종 검증 수행함.
- Terra 독립 운영 검토: 이미지 교체 도구·단일 writer·복구 조건을 검토함.
- Portal 변경 파일 6개 및 crawler-worker 변경 파일 1개의 실행 중 SHA-256이 Git 원본 blob과 일치함.
- 두 Deployment의 목표 이미지 일치, desired/ready/updated/available 각각 1, Recreate 전략을 확인함.
- 두 서비스 모두 Docker writer 0개이며 신뢰 가능한 crawler K3s runtime marker 유지됨.
- 기존 이미지 복구 가능 여부, 실행 UID 및 실제 데이터 볼륨 접근 권한을 사전 확인함.
- PVC·Secret·Caddy·Tunnel·스케줄러·런타임 소유권 변경 없음.
- 배포 전 외부 요청 1회 시간 초과가 있었음. 이후 로컬·N100 각각 두 서비스 3회 연속 200, Pod 내부 200, 배포 후 최종 3회 200으로 재검증함. 시간 초과의 상세 원인은 확정하지 않음.
- 최초 작업트리 파일 해시 비교 실패는 Windows 체크아웃의 줄바꿈 변환 영향으로 확인함. CRLF 정규화 결과가 Git blob과 일치함을 확인하고, 실제 배포 코드는 Git 원본 blob 기준으로 재검증하여 통과함.
- 앱 코드 수정은 없으므로 전체 단위 테스트를 재실행하지 않음. 기존 해당 커밋의 CI 결과와 이번 실제 운영 검증을 사용함.

## 확인 필요 사항

실제 업로드·HomeOps 실행·뉴스 알림 전송을 유발하는 운영 쓰기 테스트는 수행하지 않음. 해당 기능의 회귀 테스트는 배포 커밋의 기존 CI 검증에 따름.

## 후속 조치

전체 개발 계획의 7차부터 별도 순차 진행 필요함. 이 문서는 기존 배포 증적을 7차 개발 문서에 함께 보존한 것으로, 새 운영 적용을 의미하지 않음.
