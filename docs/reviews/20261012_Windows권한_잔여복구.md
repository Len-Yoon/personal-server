# Windows 권한 잔여 20개 복구

## 1. 문서 정보

| 항목 | 내용 | 비고 |
|---|---|---|
| 작성일 | 2026-10-12 | Asia/Seoul |
| 기준 | PR #377·#378, 이전 암호화 HELD 기록, 현재 권한 읽기 결과 | 과거 실패를 성공으로 대체하지 않음 |
| 목적 | 전체 운영 데이터 목록과 충돌하는 기존 경로를 분리하고 남은 20개만 보완함 | 구현·검증 진행 중 |

## 2. 핵심 요약

- 사용자가 새 복구 방식으로 전환하는 제안에 `진행해`로 승인함. 기존 3/3 실패 이력은 보존하며, 새 방식의 구현·검증·정확한 계획 검토 후 단일 운영 실행 범위에 적용함. 새 방식 실패 시 자동 재시도하지 않음.
- 직접 대상은 `docker-compose.n100.yml`, `docker-compose.portal-bridge.yml` 및 기존 승인 목록의 Git 디렉터리 18개임. 전체 23개를 다시 적용하지 않음.
- 프로젝트 루트·`.env`·`docker-compose.yml`의 현재 목표 권한 일치를 별도 읽기 대조로 확인함. 세 대상의 쓰기 핸들·직접 setter·원복을 새 경로에서 차단함.
- 현재는 개발 단계임. 저장소 CI가 성공하거나 시험이 통과한 사실을 N100 권한 적용·Caddy 전환·통신 차단 정책 적용 성공으로 표현하지 않음.

## 3. 상세 내용

### 3.1 확인된 원인과 현재 관측

| 항목 | 확인 결과 | 한계·비고 |
|---|---|---|
| 이전 실패 경로 | native 진단 경로 SHA가 `data/recovery.lock`과 정확히 일치함 | 당시 생성 프로세스·실행 중 코드 버전은 확인 필요 |
| 저장소 생성·삭제 코드 | `Enter-RecoveryLock`과 `Exit-RecoveryLock`에서 해당 파일을 관리함 | 당시 생성 주체를 입증하지 않음 |
| 현재 첫 3개 | 현재 Windows 실행 주체·SYSTEM·관리자에 대한 정확한 ACE 3개와 보호 상태가 목표와 일치함 | 과거 setter 횟수·소유자/그룹 보존·FileID는 이 읽기로 확인하지 않음 |
| 나머지 입력 2개 | 상속 ACE 3개·상속 차단 없음 | 새 계획에서 원본 및 목표를 다시 검증함 |
| 바이트 비교 불일치 | 개별 ACE·revision이 같고 순서만 다름을 별도 비교로 구분함 | 이후 native 원본 비교 계약은 임의 완화하지 않음 |
| 실제 읽기 증거 | SHA-256 `b988a895dc5a4438c5e967b3b1cf8f2a563c1756219378ed6d5ea7f3b699f690` | 현재 권한 의미 대조 JSON, 운영 setter·원장 쓰기 0회 |

### 3.2 새 계약의 경계

| 구분 | 허용 범위 | 제외·보존 |
|---|---|---|
| 직접 권한 변경 | 정확한 입력 2개·기존 승인 Git 디렉터리 18개 | root·기존 입력 2개의 직접 setter·원복 거부 |
| 핸들 및 목록 검증 | root·실행 입력 4개와 Git 전체 하위, 신뢰 가능한 조상 | 데이터·자동복구 파일 순회·pin·setter 없음 |

| 운영 입력 | 4개 해시를 계획 및 매 단계 검증함 | 내용·자격 증명 출력·변경 없음 |
| 원장 | 새 계약의 암호화 계획·실행 의도를 별도로 기록함 | 기존 HELD·선행 암호문과 메타데이터 유지 |
| 기존 제외 대상 | 쓰기 범위로 보존함 | Git 외 315개 별도 권한·69개 다른 소유자의 전체 재측정을 주장하지 않음 |

## 5. 확인 필요 사항

- PR 및 main CI와 실제 운영 pin·암호화 계획 검토 결과 확인 필요. 전체 로컬 검사·ACL 독립 검토·실제 Windows 소유 시험·실행기 구조 검토는 통과함.
- 저장소 병합·N100 동기화·권한 운영 적용은 아직 미수행임.
- Caddy 전환·통신 차단 정책 및 그 적용 후 24시간 관찰은 별도 미완료임.

## 6. 후속 조치

1. 새 계약을 구현하고 관련 및 필수 검사·독립 검토를 완료함.

4. 실제 권한·보존·외부 health를 확인하고 결과를 기록함. 실패나 불명확 응답이면 추가 적용 없이 보류함.
