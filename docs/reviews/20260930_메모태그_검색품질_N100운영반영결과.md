## 4. 독립 검토·보호 범위

전문 검토 담당이 적용 전 세 서비스의 단일 K3s writer·PVC Bound/RWO·2026-09-30 순차 백업 4건 성공·잠금 해제와 외부 health 12/12를 읽기 전용으로 확인함. YouTube 전환 스크립트의 공개 health 주소·모호한 patch 응답·기존 이미지 보존·Deployment/PVC UID 검사를 보완한 뒤 실행함. 적용 후에는 세 목표 Pod imageID·단일 writer·기존 DB 건수·태그 테이블·백업 잠금·외부 health 12/12를 독립 확인함. 일시적인 YouTube 태그 테이블 미생성은 새 코드의 첫 DB 조회 전 상태였고, 실제 홈·상세 조회 뒤 동일 DB에서 생성과 기존 건수 유지를 확인함.

Secret·PVC 데이터·백업 스케줄·Caddy·Tunnel·bootstrap·scheduler는 변경하지 않음. 이미지 외 Deployment 필드는 변경하지 않았으며, rollback·반복 patch는 수행하지 않음. 전송용 N100 임시 파일은 반입·검증 뒤 제거함.

## 5. 확인 필요 사항

기존 운영 메모에 대한 실제 태그 쓰기·삭제 시험은 운영 데이터 변경을 피하기 위해 수행하지 않음. 태그 입력·필터·권한은 PR 및 병합 후 CI의 회귀 테스트로 검증했고, 공개 화면의 입력 폼과 실제 DB 테이블 생성은 확인함.

## 6. 후속 조치

일상 사용에서 태그 저장·필터 동작과 검색 결과의 관련성을 관찰함. 오류가 발견되면 현재 보존된 세 기존 이미지 digest와 이 문서의 데이터 기준선을 사용해 해당 서비스만 단회 복구함.
