## 핵심 요약

N100 동기화·전용 실패 배포 및 HTTP 복구 훈련·Loki 데이터 보존 rollback 및 재설치·SLO image-only 교체는 성공함. Ansible drift 도구는 정상 응답의 CRLF와 강제 ASCII locale 문제로 주입 전에 차단됨. 운영 응답 파일을 강제 변환하거나 안전 검사를 끄지 않았으며, 도구의 일반 개발 보완을 진행함. Ansible 실제 훈련은 아직 미수행임.

## 확인 필요 사항

- Ansible 수정본의 필수 CI·병합 및 새 SHA 운영 동기화 승인, 실제 drift·원복·changed=0 훈련이 남아 있음. 독립 전문 검토는 완료함.
- 새 SLO 이미지의 다음 정기 수집 성공, Grafana 화면 렌더, CNI 접근 정책 집행, Loki 24시간 보존 이후 실제 삭제는 별도 확인 필요함.
- local-path의 1Gi 요청은 디스크 강제 quota가 아님. 전체 시간 기반 SLO·에러 버짓 확보로 과장하지 않음.

## 후속 조치

1. Ansible 호환 보완을 검토·검증·PR·CI·main 병합까지 진행하고 결과는 해당 PR에 기록함.
2. 새 수정 SHA 동기화·Ansible 훈련 추가 승인 후 해당 단계만 수행함. Loki rollback·SLO 교체를 반복하지 않음.
3. 다음 정기 수집과 시간 경과가 필요한 증거는 실제 결과를 확인한 후 별도로 기록함.
