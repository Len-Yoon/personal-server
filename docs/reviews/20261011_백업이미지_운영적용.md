## 7. 사전 검증용 원복 커밋

적용 릴리스 C2는 PR #370의 줄바꿈 보완을 포함한 main CI 성공 커밋으로 확정하며 실제 SHA를 실행 기록에 별도 기재함. 이 후속 커밋은 세 pin 파일을 C1의 원본 바이트로 복구한 사전 검증용 C3임. C3의 저장소 병합은 N100 변경이나 실제 원복을 뜻하지 않으며 운영 CronJob·실행기 참조는 별도 잠금 적용 절차에서만 변경함. 정상 적용 직후에는 N100=C2, main=C3 차이를 명시함.

정상 적용이 확인되면 C4에서 신규 아홉 pin과 실제 결과를 저장소에 복원함. C2와 C4의 전체 프로그램 트리 및 세 pin 파일 바이트가 같고 차이가 허용 문서뿐임을 검증하고, C4의 필수 CI 성공 후 기존 잠금 아래 소스만 fast-forward하여 main·운영 소스·production-state를 일치시킴. 이 정상화는 CronJob·이미지·일정·운영 데이터를 변경하지 않음. C2 또는 C4가 깨끗하게 확인되면 신규 이미지 참조가 동일하므로 유지하며, dirty·외부 커밋·자식 종료 불확실성은 잠금을 유지하고 추가 변경을 중단함.

## 9. C4 소스 정합화와 완료 기준
