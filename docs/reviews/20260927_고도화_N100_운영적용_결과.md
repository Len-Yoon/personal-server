## 2. 핵심 요약

YouTube UX PR #270 병합 후 N100 저장소를 fast-forward함. Portal 검색 계측, YouTube UX, SRE Relay 이미지를 검증된 OCI digest로 반입·전환했으며, Relay의 백업 상태·Job 조회용 읽기 전용 RBAC와 Grafana 검색 p95 패널을 적용함. 세 서비스의 새 원격 백업은 전용 Secret과 원격 공유 ACL의 출처가 확인되지 않아 실행·활성화하지 않음.

## 4. 검토 결과

운영 전문 검토 담당이 변경 전 단일 K3s writer·runtime marker·기존 리소스·보호 범위를 확인하고 YouTube 갱신/rollback 및 Grafana 단일 키 patch/rollback 스크립트를 독립 검토함. Grafana는 기존 4패널과 나머지 JSON 필드 보존, ConfigMap UID·resourceVersion·기존 값 일치를 확인한 뒤 검색 p95 패널 하나만 추가함. 세 이미지 전환과 대시보드 적용은 최초 실행에서 성공했고 rollback은 수행하지 않음. Secret·PVC·Caddy·Tunnel·운영 데이터·NetworkPolicy·호스트 pruner는 변경하지 않음.

## 6. 후속 조치

1. 승인된 암호화 저장소의 전용 자격 증명 출처와 원격 ACL을 확인한 뒤 백업 단계만 재개함.
2. 각 백업은 중지 상태로 설치해 수동 Job·격리 복원·알림을 검증하고 성공한 서비스만 자동 실행을 활성화함.
3. 검색 요청 표본이 쌓인 뒤 Grafana 패널과 p95 시계열을 확인하고 SLI·에러 버짓은 충분한 관측 자료로 산정함.
