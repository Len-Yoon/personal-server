## 4. 독립 검토·보호 범위

운영 검토 담당이 적용 전후 N100의 신뢰 가능한 K3s 실행 표식, 각 서비스의 단일 Ready Pod·Deployment/Pod 이미지 일치, Compose writer 0, PVC Bound/RWO, 백업 상태 completed·잠금 해제·활성 Job 0을 읽기 전용으로 대조함. 공개 News 날짜 입력·선택값 유지·빈 결과 안내와 비인증 export JSON/Markdown 4건의 HTTP 401을 확인함. 보관 기사가 있는 날짜의 결과 집합 자체는 운영 자료와 대조하지 않았고 PR 회귀 테스트 결과로 검증함. YouTube 이미지 전용 스크립트는 복원 전 Deployment UID·resourceVersion·기존 데이터 볼륨 연결·PVC UID/Bound/RWO를 재확인하도록 독립 검토에서 보완함. 불명확한 patch 응답은 재실행하지 않고 실제 Deployment 상태를 조회하도록 함.

Secret·PVC 데이터·백업 일정·Caddy·Tunnel·bootstrap·scheduler는 변경하지 않았으며 기존 이미지를 삭제하지 않음. 임시 전송 파일은 검증 종료 후 정리함.

## 5. 확인 필요 사항

운영 계정으로 로그인한 Book·YouTube Markdown/JSON 다운로드와 실제 파일 내용은 이번 검증에서 수행하지 않음. 전체 기록·태그·타임스탬프·권한·출력 형식은 Mac 및 PR 회귀 테스트로 검증함. 다음 정상 뉴스 수집과 다음 정기 백업의 결과는 실행 후 확인 필요함.

## 6. 후속 조치

일상 사용에서 날짜별 뉴스 조회와 두 메모 서비스의 파일 다운로드를 확인함. 장애가 발생하면 단일 writer·백업 잠금·현재 imageID를 먼저 대조하고, 보존된 직전 digest 이미지로 해당 서비스만 조건부 복원함.
