### 독립 검토 보완 및 로컬 확인

전문 독립 검토 지적 4건을 보완함: Book·YouTube 시작 시 DB 초기화 전 readiness 교착, 휴지통 이동 후 fsync 실패의 완료 사실 분리, 손상된 metadata 제외, Crawler readiness와 실제 archive loader의 검증 기준 일치. Bookmark 연결 종료와 이미지/증적의 충돌 없는 완성 파일 발행도 보완함. 최종 독립 diff 검토에 미해결 P1/P2 없음.

Portal 파일 관리 화면·개인 기사 보관 화면·Book 비인증 가져오기 로그인 안내를 임시 데이터/로컬 서버의 실제 브라우저에서 확인함. 파일 관리 폼을 기존 색상·입력 스타일과 맞추며 다른 화면 이미지·배치를 변경하지 않음. API 회귀로 이동·휴지통·충돌 복원·부분 성공·인증·Origin 차단을 검증함. 인증된 실제 브라우저 가져오기 파일 선택/저장 동작은 확인 필요함.

Trivy는 [공식 image CLI](https://trivy.dev/docs/dev/references/configuration/cli/trivy_image/)의 archive input 및 실패 exit code를 사용함. 로컬 Trivy 실행 파일이 없어 실제 final image build/scan은 미수행이며, 준비 도구 테스트를 취약점 검사 통과로 표현하지 않음. 새 도구는 기존 K3s import에 맞는 OCI archive와 image-ref annotation을 생성함. 기존 image-only 운영 적용 순서는 승인 후 유지함.
