# 소스 권한 515개 보완 실행 계획

> For agentic workers: 저장소 AGENTS.md의 기존 구현·독립 검토 분담으로 연속 실행함. 사용자 지침에 따라 계획 도구의 추가 실행 방식 선택·계획 재승인·중복 워크플로우를 생략함.

**Goal:** 승인된 파일 457개·폴더 58개의 비신뢰 쓰기·권한 변경 허용을 제거하고 목록 밖 권한을 보존함.

**Architecture:** 기존 권한 도구와 HELD 원장을 유지하고 별도 schema의 도구를 추가함. 읽기 핸들로 하위 객체와 조상을 고정하고, 명시 권한의 배타적 대상 핸들로 DACL만 설정함. 암호화 계획·실행 의도·실제 응답과 목록 밖 불변을 결합함.

**Tech Stack:** Python 표준 라이브러리, Windows PowerShell 5.1, C# Win32 핸들·보안 API, DPAPI CurrentUser.

**Spec:** 사용자의 exact515 승인 응답, 고정 대상 제안서 SHA `af546be67373c1fdb8d55ab108fd8ed7b65f26a6a39b32a69757bb60bedc0e92`, 실제 읽기 증거 SHA `e29ba52d118b1a4618980e6a1eb2aad5e9dc72db7d8feac1ac9b7043fc0f565c`임.

## Review Focus

1. 폴더 배타적 설정에도 outside515가 변할 수 있는지 실제 owned fixture와 운영 전후 전체 metadata로 확인함.
