## 2. 핵심 요약

실제 Book FastAPI/uvicorn을 Git 고정 릴리스에서 구동하여 3종×3회, 총9회 훈련을 통과함. 총18개 actor의 ready 식별을 확인했고, 구 actor가 정상 종료·회수된 후에만 다음 actor를 시작함. 데이터·실제 HTTP 읽기·자원 정리는9/9 통과함. 후보 배포 성공은 정상 재배포3회이며, 나머지6회는 의도대로 실패·차단됨.

## 5. 확인 필요 사항

동일 앱 payload의 프로세스 재배포 훈련임. 새 코드·schema 버전 호환성, 컨테이너 이미지 빌드·배포, 이미지 digest·독립 dependency 설치, 운영 트래픽 전환·무중단·외부 health·운영 MTTR/RTO/RPO는 미검증임. 릴리스의 readiness 설정 오류와 파일 변조만 의도적으로 주입함.
