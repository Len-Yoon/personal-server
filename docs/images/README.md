## 표시 기준

모든 화면 이미지와 구성도는 1440 × 1000 크기로 통일함. README에서는 동일한 전체 폭으로 한 장씩 표시함. 화면을 늘리거나 비율을 변형하지 않고 여백을 사용함. 긴 페이지는 핵심 기능 구간을 촬영하며, 페이지 전체를 축소해 글씨가 작아지는 방식을 피함.

## 원본과 공개 범위

- 공개 화면은 실제 서비스 응답을 촬영함. 관리자·파일함은 승인된 읽기 범위에서 실제 운영 HTML을 메모리로만 받아 현재 소스의 정적 자산과 함께 표시함. 인증 자격 증명과 세션 쿠키는 이미지·저장소에 저장하지 않음.
- 프레임의 제목·예시 표시는 설명용이며 서비스 데이터와 분리함. 수치·성공 상태·기사·메모를 새로 만들거나 보정하지 않음.
- 관리자 백업 표시는 원본 증거의 시각과 상태를 그대로 사용함. 이미지 교체는 운영 배포·백업 실행·삭제·인증 변경을 포함하지 않음.
- Grafana·Telegram은 새로운 촬영본이 아니므로 프레임과 README에 기존 예시임을 명시함. WSL2에서 node-exporter를 비활성화한 구성과 일부 사용률 지표의 한계를 유지함.

## 검증 기준

화면별 핵심 기능·가독성·민감정보 제외 여부를 시각 확인함. PNG 크기·형식·데이터 해제, SVG XML과 렌더링, 로컬 이미지·문서 링크 및 기존 문서 계약 검사를 확인함. 기능 영향 없는 문서·이미지 변경이므로 주 담당 1명이 수행하며 운영 변경은 수행하지 않음.
