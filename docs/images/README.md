## 원본과 공개 범위

- 서비스의 실제 브라우저 화면을 촬영함. 관리자·파일함·Book은 기존 인증 정보를 메모리에서만 사용하고 임시 브라우저 컨텍스트를 종료함. 자격 증명·세션 쿠키·개인 파일 목록을 이미지·저장소에 저장하지 않음.
- Grafana는 기존 인증으로 실제 서버 응답과 지표 질의를 읽어 표시함. 읽기 요청과 `/api/ds/query`만 허용한 임시 응답 전달 경로를 사용하며 대시보드·데이터 소스 설정은 저장하지 않음.
- 프레임의 제목·촬영 날짜는 설명용임. 수치·성공 상태·기사·메모를 새로 만들거나 보정하지 않음. 관리자 백업의 시각·상태와 Grafana의 `No data`·과할당 비율을 원본대로 유지함.
- 화면은 촬영 시점의 상태이며 지속 가용성·현재 수치·백업 복구 가능성 전체의 증거로 확대하지 않음. WSL2에서 node-exporter를 비활성화한 구성과 일부 지표의 한계를 유지함.
- Telegram은 과거 예시임을 프레임과 README에 명시함. 이미지 교체는 운영 배포·백업 실행·데이터 저장/삭제·인증 설정 변경을 포함하지 않음.

## Grafana No data 조사 결과

- 단일 Cluster UID는 `efa86fd1d0c121a26444b636a3f509a8`임. 이름의 일부만 검색하면 먼저 반환된 Multi-Cluster를 잘못 선택할 수 있어 정확한 제목·UID로 대조함.
- 단일 Cluster의 원시 쿼리 중 CPU·메모리 사용률 2개만 결측이며 node-exporter 비활성화와 일치함. 나머지 쿼리는 결과가 있고 CPU Quota는 원본 브라우저에서 네임스페이스 5개·7개 지표 열의 정상 표를 확인함. 쿼리 식별자 보완 여부와 무관하게 정상임.
- Multi-Cluster 표는 `cluster` 라벨 결합을 요구하지만 현재 단일 클러스터 지표에는 이 라벨이 없음. 이전 캡처의 표 결측을 수집 장애로 확대하지 않음.
- 컨테이너 CPU·working set과 KSM allocatable 지표는 존재하므로 별도 컨테이너 사용률 패널은 가능함. Windows·WSL 전체 사용률로 대체 표기하거나 결측을 0으로 만들지 않음. 이번 조사는 대시보드·수집·알림·운영 설정을 변경하지 않음.

화면별 핵심 기능·가독성·민감정보 제외 여부를 시각 확인함. PNG 크기·형식·데이터 해제, SVG XML과 렌더링, 로컬 이미지·문서 링크 및 기존 문서 계약 검사를 확인함. 최초 이미지 최신화는 주 담당 1명이 수행함. 2026-11-01 Grafana 정정은 주 담당의 조사·촬영·자기 검증과 작성에 참여하지 않은 별도 Sol high의 실제 원본·diff·이미지 독립 검토로 구분함. 기능·운영 설정 변경은 수행하지 않음.
