## 원본과 공개 범위

- 서비스의 실제 브라우저 화면을 촬영함. 관리자·파일함·Book은 기존 인증 정보를 메모리에서만 사용하고 임시 브라우저 컨텍스트를 종료함. 자격 증명·세션 쿠키·개인 파일 목록을 이미지·저장소에 저장하지 않음.
- Grafana는 기존 인증으로 실제 서버 응답과 지표 질의를 읽어 표시함. 읽기 요청과 `/api/ds/query`만 허용한 임시 응답 전달 경로를 사용하며 대시보드·데이터 소스 설정은 저장하지 않음.
- 프레임의 제목·촬영 날짜는 설명용임. 수치·성공 상태·기사·메모를 새로 만들거나 보정하지 않음. 관리자 백업의 시각·상태와 Grafana의 사용률·과할당 비율을 원본대로 유지함.
- 화면은 촬영 시점의 상태이며 지속 가용성·현재 수치·백업 복구 가능성 전체의 증거로 확대하지 않음. 새 수집기는 CPU·meminfo만 활성화하며 네트워크·디스크 등 다른 노드 collector는 비활성 상태임.
- Telegram은 과거 예시임을 프레임과 README에 명시함. 이미지 교체는 운영 배포·백업 실행·데이터 저장/삭제·인증 설정 변경을 포함하지 않음.

## Grafana No data 조사·복구 결과

- 단일 Cluster UID는 `efa86fd1d0c121a26444b636a3f509a8`임. 이름의 일부만 검색하면 먼저 반환된 Multi-Cluster를 잘못 선택할 수 있어 정확한 제목·UID로 대조함.
- 최초 조사에서 사용률 2개 결측은 node-exporter 비활성화와 일치했음. 이후 사용자 승인으로 고정 이미지의 CPU·meminfo 수집기를 WSL 원본과 대조하고 운영 적용함. 실제 브라우저에서 CPU 18.3%·메모리 38.9%와 정상 CPU Quota 표를 다시 촬영함. 이는 2026-11-01 22:33 시점 값임.
- Multi-Cluster 표는 `cluster` 라벨 결합을 요구하지만 현재 단일 클러스터 지표에는 이 라벨이 없음. 이전 캡처의 표 결측을 수집 장애로 확대하지 않음.
- 컨테이너 CPU·working set과 WSL2 노드 전체 통계는 구분함. Windows 사용률로 대체 표기하거나 결측을 0으로 만들지 않음. 기존 대시보드·recording·경보는 변경하지 않았으며 별도 Git 소유 최소 수집기 4개 자원만 추가함. [운영 검증](../20261101_Grafana_WSL_CPU메모리_운영검증.md)에 적용·원복 경계를 기록함.

## 검증 기준

화면별 핵심 기능·가독성·민감정보 제외 여부를 시각 확인함. PNG 크기·형식·데이터 해제, SVG XML과 렌더링, 로컬 이미지·문서 링크 및 기존 문서 계약 검사를 확인함. 최초 이미지 최신화는 주 담당 1명이 수행함. 2026-11-01 후속 수집기 적용은 구성·절차 구현과 독립 Sol high의 사전·실제 N100 사후 검토를 분리했으며, 주 담당은 실제 렌더 촬영·이미지 자기 검증을 수행함. 이번 문서·이미지 반영 자체는 운영 리소스를 변경하지 않음.
