# 단일 N100 개인 서비스 운영과 데이터 이중화

## 프로젝트 개요

단일 Intel N100으로 Portal을 포함한 개인 서비스 7개를 운영했습니다. Windows의 Cloudflare Tunnel·Caddy를 외부 진입점으로 두고, Hyper-V Linux VM A에 앱과 PostgreSQL 쓰기를 배치했습니다. VM B는 PostgreSQL 동기 대기를 담당합니다.

## 가장 어려웠던 점

N100의 제한된 CPU·메모리로 Windows, 두 VM, 일곱 앱을 함께 운영하는 것이 가장 어려웠습니다. 평상시 사용량과 장애 복구 중 기동 부하를 따로 보고, B를 동기 대기로 운영하며, DB 두 대의 상태를 확인한 후 A에만 쓰기 권한을 발급했습니다.

## 장애 해결

앱 복구 중 Windows 권한 확인이 6초를 넘겼을 때, 같은 Windows 연결에서 갱신이 겹친 읽기만 한 번 더 확인하도록 바꿨습니다. 재확인은 약 4.4~4.5초에 통과했습니다. 삭제와 재생성 없이 앞선 기동 기록을 이어받아 앱 7개와 내부 브로커를 재개했고, Portal 첫 화면과 공개 health 3회를 HTTP 200으로 확인했습니다.

## 운영 범위

두 VM은 하나의 물리 호스트를 공유합니다. 현재 운영 경로와 단일 쓰기·동기 복제는 검증했습니다. 호스트 재부팅 뒤 자동 복구와 물리 호스트 장애 대응은 남은 과제입니다.
