## 2. 핵심 요약

먼저 사용자 기능 장애와 데이터 손실을 수정하고 검증 체계를 보강함. 이후 운영 자동복구·데이터 처리·문서를 정리하며, 대규모 고도화는 기존 결함 수정 뒤에 설계함. 단계별로 구현, 관련 테스트, 정적 검사, 독립 검토, 하네스 결과를 기록한 뒤 다음 단계로 이동함.

1차는 이미 원인과 수정 경계가 확정된 F01을 실행함. 2차 HomeOps는 F02 단독 활성화 시 F03·F04 위험을 드러낼 수 있으므로 하나의 안전성 묶음으로 취급함. 운영·보안 영향이 있는 2차는 구체 범위를 제시한 뒤 2026-09-21 사용자에게 로컬 코드·테스트 변경 승인을 받았음. 실제 운영 적용은 승인 범위에 포함하지 않음.

- 사용자 화면의 주소·응답 계약을 보존함. 시간 신규 저장은 UTC aware ISO 8601, 표시·날짜 판단은 Asia/Seoul, 표시 형식은 `YYYY-MM-DD HH:MM`을 유지함.

## 2026-10-05 DevOps 증거 고도화

사용자의 네 항목 전체 진행 요청에 따라 Loki 기동 검증 retry, 전용 namespace 실패 배포·HTTP 복구 훈련, Ansible 응답 drift·멱등성 훈련, 기존 SLO 일일 증적의 읽기 전용 집계를 구현함. SLO 공개 요청의 HTTP 403을 같은 실행 환경에서 재현해 고정 User-Agent만 보완함. 주 담당은 통합·집계·문서를, 두 구현 담당은 독립된 실습 도구를, 전문 검토 담당은 소유권·rollback·프로세스 종료·운영 경계를 검토함.

관련 검사 125건과 독립 전문 검토를 통과함. 필수 전체 CI·PR·병합 결과는 [검증 결과](reviews/20261005_DevOps실습고도화_검증결과.md)에 기록함. 새 N100 실습 및 SLO 운영 이미지 변경은 아직 수행하지 않음. 운영 앱·기존 PVC 데이터·Secret·기동·일정은 보존하며 정확한 커밋과 실행 순서를 준비한 뒤 최종 운영 승인을 확인함.

### 후속 운영 적용 및 Ansible 호환 보완

사용자가 `91cdb26` 동기화와 네 운영 항목을 명시 승인하여 동기화·격리 실패 배포와 HTTP 복구·Loki 데이터 보존 rollback 및 재설치·SLO image-only 교체를 완료함. 기존 monitoring 6개 UID·generation·Ready, Loki PVC UID·이전 로그, SLO 증적 hash·02:15 KST 일정을 보존함. Portal 전후 각 3회 정상 및 독립 운영 사후 검토를 확인함. 앞 절의 미수행 상태는 승인 전 기록이며 최신 결과는 [운영 적용 결과](reviews/20261005_DevOps실습_운영적용결과.md)를 따름.

Ansible drift는 Windows checkout의 CRLF와 강제 ASCII locale로 주입 전에 차단됨. 주 담당은 운영 실행·문서·통합을, 구현 담당은 drift 도구와 회귀 테스트만, 전문 검토 담당은 코드·격리 리허설·원격 사후 상태를 독립 검토함. LF·CRLF 원본 보존과 설치된 UTF-8 locale 선택을 보완하여 관련 32개 검사 및 Ansible Core 2.19.13의 실제 격리 리허설을 통과함. [PR #334](https://github.com/Len-Yoon/personal-server/pull/334)을 `0789890`으로 병합했으며 PR/main 전체 CI·Trivy를 통과함.

후속 승인으로 N100을 `0789890`에 동기화하고 실제 drift 훈련을 수행함. 소유권·baseline·drift 감지는 통과했으나 template atomic rename 후 Compose 단일 파일 bind가 기존 drift inode를 참조해 원복·복구가 실패함. 독립 확인 후 전용 sample만 1회 재생성하여 원본 CRLF·파일 해시·권한·정확한 HTTP를 회복했고 monitoring 6개·Loki PVC·SLO 이미지·증적·일정 및 Portal 전후 각 3회 정상은 보존됨. 최초 훈련 실패는 유지하고 별도 원상복구 성공으로 기록함.

후속 보완은 파일 변경 또는 소유 확인된 sample의 stale HTTP일 때만 재생성하여 중단 후 복구와 정상 2회차 무변경을 함께 확보함. 주 담당은 운영·문서·통합, 구현 담당은 site playbook·계약 회귀, 전문 검토 담당은 파일 bind 경계·복구·운영 사후 검토로 분담함. [PR #335](https://github.com/Len-Yoon/personal-server/pull/335)를 `6a17f5a`로 병합했고 관련 35건·maintenance 566건 및 PR/main 전체 CI·Trivy를 통과함.

사용자의 “적용해” 승인 후 N100을 정확한 `6a17f5a`로 fast-forward하고 Ansible 재훈련을 수행함. 소유권·baseline·drift 감지·원복·멱등성·전체 실행 모두 PASS, 실제 2회차 changed=0을 확인함. 원본 CRLF·파일 해시·권한·정확한 HTTP와 monitoring 6개·Loki PVC·SLO 이미지·일정·증적이 보존됐으며 Portal 전후 각 3회 HTTP 200을 확인함. 이미지 추가 반입·자동 실행 활성화·Loki rollback·SLO 교체 반복은 수행하지 않음. 최초 실패와 수동 복구를 소급 대체하지 않고 최종 성공 증적을 별도 기록함.
