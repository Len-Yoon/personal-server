# 프로젝트 개발·검증 현재 상태

## 문서 개요

현재 기능·운영 적용과 남은 검증을 정리함. 날짜별 작업일지·PR별 진행과 승인 대기 경과를 누적하지 않음. 실제 운영 보호 기준은 [AGENTS.md](../AGENTS.md)를 따름.

## 현재 완료 기능

| 영역 | 현재 상태 | 비고 |
|---|---|---|
| Portal | 통합 검색·파일 관리·개인 기사 보관·관리자 상태와 백업 표시 운영 반영 | 서비스 실패·파일 부분 실패·인증/초안 보호 구분 |
| Book·YouTube | 메모 편집·충돌/재시도 보호·선택 내보내기·JSON 가져오기·휴지통 운영 반영 | 기본 HTML 제출과 브라우저 동작 유지 |
| 뉴스 | 수집/알림·영속 상태·수집 최신성 운영 반영 | K3s 단일 writer 유지 |
| 차량 | 정비 명령·중복 방지·DB 암호화 백업·보관 정리 운영 반영 | OAuth·자격 증명 데이터는 백업 대상 제외 |
| 관측·복구 | 내부 지표·외부 health·제한형 복구·SLO 증적·월간 감사 | 지표 누락과 미검증 영역을 정상으로 확대하지 않음 |
| 검증·배포 | 서비스별 회귀·브라우저·계약 검사·CI/보안 검사·운영 이미지 교체 | 저장소 검증과 실제 운영 적용 분리 |

## 현재 백업 운영

- 매일 02:30 KST Portal→Book→YouTube→Crawler→차량 DB로 연결함. 기존 네 단계 모두 성공한 뒤 차량을 호출함. 별도 05:30 차량 timer는 중지됨.
- 차량은 내용이 같으면 업로드·원격 정리를 생략하고 일요일에는 실제 백업·복원을 검증함.
- 차량 보관은 일간 7·주간 4·월간 3과 전체 최신 7개 안전 하한·같은 초 동률 보존을 사용함. 최신 실복원·정확 계획·inventory·암호문 digest 검증 뒤에만 삭제함.
- 30일 지난 성공 Pod·완료 journal 쌍은 검사당 최대 1개 정리함. 최신·실패·불확실 기록과 백업/보관 증적·삭제 기록은 보존함.
- 5분 모니터는 09:00 이후 당일 미완료를 통보하며 새 백업을 실행하지 않음. 생산자 잠금 점유 시 게시·알림·정리를 유예함.
- 관리자 표시는 원본 복원 시각·유효 기간·최근 실행·정리 결과를 구분함. 차량 복원 증거는 원본 시각+8일이며 관측이나 변경 없음으로 연장하지 않음.

## 운영 적용과 검증 기준

검증된 실행 소스는 9653713e3a052b5013b8b607667a52371a261a57임. Portal·Relay 이미지 반입과 순차 교체, 실제 인증 관리자 차량 표시·비인증 상세 숨김·no-store를 확인함. 기존 파일·메모 DB·보호 객체·다른 앱 실행 주체·일정과 차량 worker 보존 및 잠금 해제를 대조함. 운영 검증은 Portal 외부와 Relay 내부 허용 경로 각각 10초 간격 3회 정상 응답을 확인함.

## 확인 필요 사항

|---|---|
| 차량 포함 전체 정기 실행 | 새 구성의 첫 다섯 단계 자동 실행 결과 관찰 |
| 실제 자동 삭제 | 기간 경과 원격 사본과 30일 성공 기록의 실제 처리 관찰 |
| 알림 | Telegram 단말 최종 수신·장기 인증 유지 |
| 관측 | SLI·에러 버짓·RTO/RPO 종합 실측, Grafana 일부 지표·로그 retention·디스크 경보 |

## 운영 승인 경계

일반 개발은 AGENTS.md에 따라 구현·검증·검토·PR/CI·병합까지 진행함. 새로운 운영 변경은 대상·동작·순서를 준비한 뒤 유효한 승인을 확인함. Secret·PVC·운영 데이터·bootstrap·scheduler·Caddy·통신 정책을 일반 개발 범위로 확대하지 않음. 추가 Windows 권한·Caddy 전환·통신 차단 정책 작업은 중지 상태이며 자동 재개하지 않음.

## 완료소진된 일회성 승인 이력

| 범위 | 승인 현재 상태 | 적용 원칙 |
|---|---|---|
| 기존 앱·메모 화면·휴지통 배포 | 완료 | 새 배포에 재사용하지 않음 |
| 차량 원격 백업·순차 연결·자동 보관/누락 감지 | 승인 범위 적용 완료 | 기존 정기 실행과 보관 정리는 유지하며 범위 밖 변경은 별도 확인 |
| Portal·Relay 차량 백업 표시 이미지 교체 | 완료 | 정확 소스/이미지의 단일 전환 승인이며 새 변경에 재사용하지 않음 |
| 중지된 Windows 권한·Caddy·통신 정책 | 재개 승인 없음 | 이전 일회성 승인을 재시도·대상 확대의 근거로 사용하지 않음 |

## 후속 조치

서버의 정기 백업·모니터를 유지하고 남은 실행 관찰은 현재 증적을 기준으로 판정함. 새 기능이나 운영 변경은 필요성이 확인된 경우에만 범위와 성공 기준을 정함. [운영 참조](operations-reference.md)·[차량 자동화](../car-care-worker/tools/automation/README.md)·[면접 자료](portfolio-devops.md)를 참조함.
