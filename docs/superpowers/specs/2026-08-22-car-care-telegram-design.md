# Telegram 차량관리 서비스 설계서

## 1. 문서 정보

| 항목 | 내용 |
|---|---|
| 문서명 | Telegram 차량관리 서비스 설계서 |
| 작성일 | 2026-08-22 |
| 기준 차량 | 더 뉴 그랜저 3.0 LPi, 블루링크 가입 차량 |
| 목적 | 정비 주기 및 차량 경고등·운행 결과를 Telegram으로 알림 |
| 범위 | 차량관리 전용 서비스, 전용 SQLite DB, Telegram Bot, Hyundai Developers API 어댑터 |
| 제외 범위 | 기존 뉴스 서비스, 기존 뉴스 스케줄러, 기존 서버 기동·배포 영역 |

## 2. 핵심 요약

- `car-care-worker`를 기존 뉴스 수집 서비스와 분리된 독립 컨테이너로 추가함.
- 초기 정기 관리 대상은 엔진오일과 미션오일로 한정함.
- Hyundai Developers API가 미연결 상태여도 Telegram 명령을 통한 수동 주행거리 갱신과 정비 알림은 동작함.
- API 권한이 승인되면 누적 주행거리·주행 가능 거리·경고등을 조회하여 운행 종료 요약과 경고 알림을 자동화함.
- 엔진오일, 브레이크오일, 타이어 공기압, 워셔액, 주유 경고등을 즉시 알림 대상으로 관리함.

## 3. 아키텍처

```text
Telegram Bot API
        │
        ▼
car-care-worker
  ├─ 명령 처리: 상태 조회·주행거리 갱신·정비 완료 기록
  ├─ 알림 판정: 정비 임박·초과, 경고등 상태, 운행 종료
  ├─ Hyundai API 어댑터: 초기 비활성, 승인 후 활성화
  └─ SQLite: 차량 상태·정비 이력·알림 발송 상태
```

### 3.1 데이터 흐름

1. Telegram에서 명령을 수신하거나 차량 상태를 주기적으로 조회함.
2. 누적 주행거리와 주행 가능 거리, 경고등 상태를 전용 DB에 저장함.
3. 엔진오일·미션오일의 마지막 교환 기준과 현재 누적 주행거리를 비교함.
4. 알림 조건이 충족되면 중복 발송 여부를 확인한 뒤 Telegram으로 전송함.
5. 주행거리 증가 후 일정 시간 동안 변동이 없으면 운행 종료로 판단하여 운행 결과를 발송함.

## 4. 기능 상세

### 4.1 Telegram 명령

| 명령 | 처리 |
|---|---|
| `/차량` | 누적 주행거리, 주행 가능 거리, 다음 정비 시점을 조회함 |
| `/주행거리 <km>` | 누적 주행거리를 수동 갱신하고 정비 상태를 재계산함 |
| `/정비완료 엔진오일 [km]` | 엔진오일 교환일·교환 주행거리를 기록함 |
| `/정비완료 미션오일 [km]` | 미션오일 교환일·교환 주행거리를 기록함 |
| `/정비목록` | 관리 항목과 적용 주기를 표시함 |
| `/알림테스트` | Bot 설정 및 수신 가능 여부를 확인함 |

### 4.2 정기 정비 기준

| 항목 | 교환 기준 | 사전 알림 |
|---|---:|---:|
| 엔진오일 | 10,000km 또는 12개월 | 1,000km 또는 30일 전 |
| 미션오일 | 60,000km | 5,000km 전 |

기본값은 초기 등록값이며, 차량 취급설명서 및 실제 정비 이력에 따라 Telegram 명령으로 변경 가능하게 구현함.

### 4.3 경고등 알림

| 경고 대상 | 처리 |
|---|---|
| 엔진오일 | 감지 즉시 알림 |
| 브레이크오일 | 감지 즉시 알림 |
| 타이어 공기압 | 감지 즉시 알림 |
| 워셔액 | 감지 즉시 알림 |
| 주유 | 감지 즉시 알림 |

같은 경고 상태는 최초 1회만 알림. 해제된 뒤 다시 감지된 경우에만 재발송함.

### 4.4 운행 종료 요약

주행거리가 증가한 후 설정된 유휴 시간 동안 변동이 없으면 운행 종료로 추정함. Telegram으로 다음 정보를 보냄.

```text
[운행 결과]
이번 운행: 18.4km
누적 주행거리: 52,340km
현재 주행 가능 거리: 412km
엔진오일 교환까지: 1,660km
```

공식 API에 시동 OFF 이벤트가 보장되지 않으므로, 운행 종료 알림은 지연되거나 장기 통신 불가 상태에서 누락될 수 있음. 연료 사용량은 공식 API 제공 범위가 확인되지 않아 표시하지 않음.

## 5. 외부 연동 및 보안

| 구분 | 내용 |
|---|---|
| Telegram | `CAR_CARE_TELEGRAM_BOT_TOKEN`, `CAR_CARE_TELEGRAM_CHAT_ID`만 허용함 |
| Hyundai API | Hyundai Developers 상용 권한 및 사용자 데이터 제공 동의 후 활성화함 |
| API 미연결 | 수동 주행거리 입력 기능만 제공함 |
| 비밀값 | `.env`에만 저장하며 로그·Telegram 메시지·저장소에 기록하지 않음 |
| 개인정보 | 차량 번호, 차대번호, 위치, 현대 계정 정보는 Telegram에 표시하지 않음 |

## 6. 오류 처리

- Hyundai API 조회 실패는 차량 경고가 아닌 운영 오류로 분리하고, 하루 1회만 알림.
- Telegram 발송 실패는 발송 상태를 기록하지 않아 다음 주기에 재시도 가능하게 함.
- 잘못된 Telegram 명령은 사용법을 응답하며 기존 정비 이력을 변경하지 않음.
- 권한 미설정 상태에서는 자동 조회를 건너뛰고 수동 모드임을 `/차량` 응답에 표시함.

## 7. 검증 기준

| 구분 | 검증 내용 |
|---|---|
| 정비 판정 | 엔진오일·미션오일의 임박·초과·완료 후 초기화 처리 검증 |
| 경고등 | 최초 감지·해제·재발생 시 알림 중복 방지 검증 |
| 운행 요약 | 운행 시작·유휴 종료·중복 발송 방지 처리 검증 |
| Telegram | 허용 채팅만 명령 처리하고 메시지 형식 검증 |
| 범위 | 기존 뉴스 서비스·뉴스 스케줄러 무변경 및 `git diff --check` 검증 |

## 8. 확인 필요 사항

- Hyundai Developers 상용화 승인 및 더 뉴 그랜저 3.0 LPi의 실제 데이터 응답 범위 확인 필요.
- 시동 OFF 이벤트 미제공 시 운행 종료는 유휴 시간 기반 추정으로 처리 필요.
- 엔진오일·미션오일의 실제 마지막 교환 주행거리 입력 필요.
