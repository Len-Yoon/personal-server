# 설계·구현 이력 보관함

`specs/`와 `plans/`는 기능 착수 당시의 설계, 구현 순서, 검토 기록을 보존하는 이력 문서임. 현재 운영 절차나 현재 기능 범위를 판단하는 기준 문서가 아님.

## 사용 기준

| 구분 | 사용 목적 | 현재 운영 판단에 사용 여부 |
|---|---|---|
| `specs/` | 당시의 설계 의도와 제약 확인 | 사용하지 않음 |
| `plans/` | 당시의 구현 순서·검증 기록 확인 | 사용하지 않음 |
| `specs/2026-08-19-homeops-approved-operations-design.md` | 현재 HomeOps 권한·정책·제한의 상세 근거 | 운영 참조와 함께 사용함 |

서비스명, 포트, 환경변수, 배포 명령, 정기 점검 주기는 [운영 문서 색인](../README.md)의 현재 운영 문서를 우선함.
