계획의 체크박스만으로 완료 여부를 판단하지 않음. 아래 표의 확인 필요는 미구현을 뜻하지 않으며, 계획 전체와 커밋·검증 증적의 추가 대조가 필요하다는 의미임. 과거 운영 절차는 [현재 운영 참조](../../operations-reference.md)를 우선함.

1~5차 앱 배포 근거는 [2026-09-21 배포 검증 결과](../../reviews/20260921_앱배포_검증결과.md)임. 이후 수정은 해당 배포에 포함되지 않음. 활성 스케줄러 상태는 [운영 상태 기록](../../operations-reference.md#운영-상태-확인-기록)을 따름.
