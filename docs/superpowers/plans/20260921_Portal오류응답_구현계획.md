# Portal 오류 응답 구현 계획

> 승인된 8차 F08·F12. subagent-driven-development로 테스트 우선 구현함.

## 목표와 경계

관리자 보안 API 인증 성공 시 실제 JSONResponse에 기존 no-store 헤더를 설정하여 200 JSON을 반환함. 비허용 사용자 이벤트는 기존 의도인 무시·감사 기록·정상 반환을 유지하며 중복 인자 TypeError를 제거함. 인증·CSRF·허용 목록·민감 정보 보호 정책은 변경하지 않음. 실제 운영·Secret·scheduler 변경 없음.

주담당 계획·통합, Luna 구현, Terra 보안 독립 검토. 같은 파일 동시 수정 금지.

## Task 1: 관리자 JSON 응답과 거절 감사 로그

파일: portal-web/app/routers/admin.py, portal-web/app/services/security.py, tests/test_portal_security.py 및 실제 라우트 검증에 필요한 기존 테스트 모듈만.

- [x] 실제 GET /admin/security의 인증성공 200 JSON·Cache-Control no-store·기존응답본문 보존, 잘못된 인증/미설정 실패를 임시환경·fake로 검증하여 기존500 재현.
- [x] fastapi.responses.JSONResponse로 security_status 결과를 감싼 후 _disable_cache 적용.
- [x] 비허용 이벤트 기록의 event 중복 인자 문제를 재현하고 요청 이벤트를 별도 detail key에 저장. 기존 _clean_detail로 크기·문자 제어 기준 적용. 허용 목록 확대 없음.
- [x] 실제 POST /admin/events의 비허용 이벤트가 500없이 기존 무시응답을 반환하고 user_event_blocked만 기록되는지 검사. 허용이벤트 정상회귀 유지.
- [x] Portal 묶음·maintenance 및 AST·diff·독립 보안 검토·하네스 통과 후 저장소반영.
