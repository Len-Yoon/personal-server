# 운영 문서 정합성 구현 계획

## 목표

Trivy 차단 정책과 실제 백업 실행 주체를 현재 증거에 맞춤. 저장소 기본값, 저장소 반영, 현재 운영 상태, 과거 성공 기록을 분리함. 과거 계획 checkbox는 그대로 보존하고 중앙 상태표를 둠.

## 변경 범위

- docs/operations-roadmap.md: Trivy fs/config HIGH·CRITICAL exit-code1, 기준일과 증거 범위 명시. 백업은 실제 portal-pvc-backup CronJob으로 표기.
- docs/operations-reference.md: 사용자 timer 단정 제거, 2026-09-21 읽기조회표(백업 CronJob활성·timer비활성·월간활성·분기중지·SLO마지막성공) 추가.
- docs/recovery-drill.md: 정적 suspend 기본값과 실제 활성상태 구분, 최신증거표연결. 새로운 훈련실행·스케줄러변경없음.
- docs/README.md: 현재운영검증표로 링크. 기존 superpowers/ 경로미노출 계약 유지.
- docs/superpowers/plans/README.md: 과거계획별 저장소상태·운영상태·근거·후속조치표. 상위개발계획에서 연결함. 자료없는항목은 확인필요로 표시. checkbox만으로미완료/완료단정금지.
- docs/20260921_프로젝트보완_개발계획.md: 실제7~10차 PR·검증·병합/보류상태 및 이번문서완료 기록.

## 근거

주담당 실제원격읽기조회 /tmp/phase11-live-facts.md. 검토담당 /tmp/phase11-design.md는 문서초안이며 live근거는 주담당검증을 기준으로보완함. 1~5차 실제배포는 docs/reviews/20260921_앱배포_검증결과.md, 6차 CI는 PR231 근거를 사용함.

## 검증

문서 relative링크·사실대조·documentation_index 및 maintenance 하네스필수검사. 기능영향없는문서라 새테스트작성·전체테스트반복없음. 운영상태확인필요는 작업미완료와구분. 계획전체본문일괄고치지않음.

## 검증 결과

문서 색인 27건·변경 문서 상대 링크·diff 검사 통과. 하네스 필수 추가 검사 없음. 기능 영향 없는 문서 변경이므로 전체 테스트는 반복하지 않음. 주 담당이 작성·실측 조회를 수행하고 Terra 독립 검토에서 timer 상태 과도한 단정과 SLO 일정 누락을 보완하여 최종 통과함. 운영 변경은 미수행함. SLO 최근 Job 실패 원인과 증적 복구는 별도 후속 조치임.
