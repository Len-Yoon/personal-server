# Book 데이터 정합성 구현 계획

> 실행 방식: 승인된 연속 진행과 subagent-driven-development. 7차 F07·F09의 제한된 결함 수정임.

## 목표와 설계

조회로 상태·진행률·수정 시각이 변경되지 않도록 함. 목차 없는 책은 수동 값을 그대로 사용하며, 목차가 있으면 체크 개수로 표시 값을 계산함. 목차 수정 시 기존 동기화는 유지함. 수동 진행 입력과 목차의 우선순위는 목록·상세에서 동일하게 적용함. 마지막 목차 삭제는 명시적 쓰기이므로 기존 초기화 동작을 유지함. 기존 DB schema·데이터를 일괄 수정하지 않음.

메모 생성 트랜잭션에서 요청한 목차가 해당 책 소속인지 검사하고 없거나 다른 책이면 ValueError로 거절함. HTTP 계층은 기존 400 변환을 사용함. 거절 시 메모·책 수정 시각 변경이 없어야 함.

## 역할과 경계

주 담당은 계획·하네스·통합·PR, Luna는 아래 코드·테스트, Terra는 독립 검토를 담당함. 같은 파일 동시 수정 금지. 실제 운영 적용·DB·PVC·Secret·scheduler 변경은 제외함. 기존 시간 저장 계약을 변경하지 않음.
