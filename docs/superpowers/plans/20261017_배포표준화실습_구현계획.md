# 로컬 배포 표준화 실습 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for the primary implementation, with the separately assigned artifact implementer and independent expert review.

**Goal:** 고정 릴리스로 실제 Book 앱을 재배포하고 readiness 실패·1회 롤백·변조 사전 차단을 증명함.

**Architecture:** Git artifact helper → 부모 감독기 → 소유 socket·DB의 uvicorn actor. 이전 actor 회수 후에만 다음 writer를 시작함.

**Tech Stack:** 기존 Book Python·FastAPI·uvicorn·sqlite3·multiprocessing·httpx 환경.

**Spec:** [설계서](../specs/20261017_배포표준화실습_설계서.md)

## Global Constraints

- 클라우드·새 VM·N100·운영 정책·제품 소스 변경 없음.
- 전체180초·IPC12초·probe5초·정리10초, 반복1~3회.
- 같은 앱 source 재배포이며 새 코드·컨테이너·무중단 성공 주장 금지.
- rollout 실패를 rollback 성공으로 덮지 않음. rollback은1회.

## Review Focus

- Git/archive 경로·link·추가 파일·digest 위조 → 쓰기/시작 전 거부.
- 부모 환경·import 오염 → 제품 import 전에 whitelist·artifact 루트 고정.
- 이전 actor 종료 실패 → 새 writer 시작 금지.
- 후보 실패·rollback 실패 → 배포 실패 유지·추가복구 금지.
- 종료·정리 실패 → 부분 증거 보존, 성공 판정 금지.

## Task 1: 릴리스 artifact

**Files:** `book-memo/tools/release_artifact.py`, `tests/test_release_artifact.py` (구현 담당 전용).
**Interfaces:** 설계 3.2의 build_release/verify_release, dict descriptor·release.json.

- [x] 실제 Git payload·digest·tamper·malicious tar·비소유 경로 회귀 RED.
- [x] bounded archive extraction·불변 manifest·정확한 파일 목록 검증 GREEN.

## Task 2: 실제 앱 actor·감독기

**Files:** `book-memo/tools/release_actor.py`, `book-memo/tools/deployment_standard_lab.py`, `tests/test_deployment_standard_lab.py` (주 담당 전용).
**Interfaces:** `release_actor(connection, release_path, expected, db_path, socket)`는 spawn target. ready 뒤 `seed`, `snapshot`, `stop` 명령에 ok/data 응답. ready는 artifact digest·PID·owner 포함. snapshot은 실제 서비스 논리 자료 해시·integrity·고정 fixture 검사값임. 부모가 HTTP /health·manifest readiness_path를 검사함.

- [x] 실제 재배포·readiness404 후 rollback·preflight변조 차단 회귀 RED.
- [x] single writer·환경 격리·부분 증거·상한·소유 정리 구현 GREEN.
- [x] rollback 실패1회·이전 종료 실패·프로세스 crash·deadline·시그널·출력 보존 회귀.
