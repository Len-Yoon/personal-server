# HTTP 지표 메모리 구현 계획

> 실행 방식: 승인된 연속 진행. 테스트 우선 구현과 독립 검토를 적용함.

## 목표와 기준

- 기준: [종합 점검 F06](../../reviews/20260921_프로젝트_종합점검보고서.md), [상위 개발 계획](../../20260921_프로젝트보완_개발계획.md)의 5차.
- 고정 method·route 조합에서 요청 수에 비례하는 duration 원본 보관과 scrape 반복 순회를 제거함.
- 지표 이름, label, bucket 경계, 누적 bucket, +Inf, count, sum 출력과 음수 0 보정은 유지함.
- method 정규화와 label cardinality 제한은 기존 계약 변경이므로 이번 범위에서 제외함. 새 label 조합에 따른 증가는 여전히 가능함.
- N100 이미지·K3s·배포 정책·scheduler·운영 데이터는 변경하지 않음.

## 설계

관측 시 고정 8개 bucket 누계·count·sum만 갱신하고 RLock으로 보호함. render는 같은 lock 아래 request 및 histogram 집계의 일관된 스냅샷을 만든 후 문자열을 생성함. 고정 label당 보관 메모리와 scrape 작업량은 원본 요청 수에 비례하지 않음.

## 역할과 파일

| 담당 | 파일·범위 | 완료 기준 |
|---|---|---|
| 주 담당 | 본 계획·상위 계획·검증·PR 통합 | 하네스 및 관련 묶음 통과, 운영 상태 분리 |
| Luna 구현 | `portal-web/app/services/http_metrics.py`, `tests/test_portal_http_metrics.py` | 메모리 회귀 RED→GREEN, 출력·동시성 계약 유지 |
| Terra 독립 검토 | 전체 diff·경계 테스트·운영 제외 확인 | 필수 수정 없음 |

같은 파일의 동시 수정은 수행하지 않음.
