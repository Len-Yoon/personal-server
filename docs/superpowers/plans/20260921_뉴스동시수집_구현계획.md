# 뉴스 동시 수집 안전성 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** F13 동일 프로세스의 동시 뉴스 수집·조회 purge·digest ack가 다른 요청의 기사와 pending을 잃지 않도록 함.

**Architecture:** 재진입 archive lock으로 최신 load/normalize/purge/merge/enqueue/save를 원자화함. RSS는 lock 밖에서 실행함. 별도 process-local notification lock으로 digest select/send/ack를 직렬화하되 archive lock은 select와 최신 상태 ack에만 짧게 보유함. schema 변경 없음.

**Tech Stack:** Python threading RLock/Lock, unittest, 임시 JSON fixture.

**Spec:** [상위 계획](../../20260921_프로젝트보완_개발계획.md) F13 및 단계별 연속 반영 승인.
