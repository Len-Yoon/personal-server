# 백업 운영 목표 상태 구현 계획

1. 기존 설치용 manifest와 N100에서 읽기 전용으로 확인한 세 CronJob의 일정·이미지 digest를 대조함. 변경 경로 하네스를 먼저 실행함.
2. 운영 목표 JSON과 검증 테스트를 작성함. 설치용 manifest와 일정·시간대·마감의 일치, 잘못된 입력, live 이미지·상태 드리프트, no-op·제한 patch를 검증함.
3. 로컬 검증, 읽기 전용 운영 점검, 최종 승인 후 제한 적용을 구분하는 도구를 구현함. 승인 전 N100 쓰기는 수행하지 않음.
4. `AGENTS.md`와 운영 절차에 맥 개발·테스트·PR·CI → 승인 → N100 정확한 커밋 동기화·적용·검증 경계를 명시함.
5. 관련 테스트·정적 검사·하네스·독립 운영 검토를 수행하고, PR CI와 리뷰 확인 후 병합함. 병합 뒤 N100 적용은 구체 결과를 제시해 최종 승인 지점에서 멈춤.
