# YouTube 메모 타임스탬프·수정 인증 구현 계획

## 목적과 범위

기존 영상 상세 화면에서 메모에 적은 재생 시각으로 이동할 수 있게 하고, 쓰기 로그인 후 메모 수정에 동일 비밀번호를 다시 요구하는 불일치를 해소함. 공개 조회와 검색, 메모 저장 원문, 기존 영상 URL·DB 스키마를 보존함. N100 운영 리소스와 배포 설정은 변경하지 않음.

| 경계 | 계약 | 검증 |
|---|---|---|
| 입력·저장 | 메모 본문의 `M:SS` 또는 `H:MM:SS`는 일반 텍스트로 저장함. 수정·검색도 원문을 사용함 | 생성·수정 뒤 DB 값 확인 |
| 표시 | 유효한 초(`00`~`59`), 세 부분 형식의 분(`00`~`59`), 24시간 미만 시각만 링크화함. 나머지는 일반 텍스트로 표시하고 HTML은 자동 이스케이프함 | 경계값·악성 HTML·다중 시각 조회 테스트 |
| 이동 | 링크의 기본 URL은 동일 영상의 YouTube 재생 시각을 가리킴. 화면에서는 현재 iframe의 `start`만 바꿈 | 링크의 영상 ID·초 값·iframe 대상 확인 |
| 인증 | 메모 수정은 다른 쓰기·삭제 작업과 동일한 쓰기 세션만 요구함. 비로그인 요청의 기존 401/브라우저 로그인 전환을 유지함 | 로그인 전·후 수정 및 로그아웃 회귀 |
| 문서 | README의 타임스탬프 기능 설명을 실제 구현 동작으로 구체화함 | 문서 계약 테스트 |

## 구현 순서

1. `tests/youtube_memo/test_ui_contract.py`에 세션 수정·타임스탬프 원문/링크/안전성 회귀를 먼저 추가하고 실패 확인함.
2. `youtube-memo/app/main.py`, `youtube-memo/app/services/memo_service.py`, `youtube-memo/app/templates/video_detail.html`을 최소 변경함. JavaScript가 없어도 YouTube 이동 링크는 작동하게 함.
3. README를 정정하고 YouTube 관련 테스트, 문서 계약, 구문·diff·하네스를 확인함.

## 배포·잔여 경계

저장 형식 변경이나 데이터 마이그레이션이 없음. 실제 N100 적용은 이 계획에 포함하지 않음. YouTube embed의 외부 재생 가능 여부는 외부 서비스 상태에 좌우되므로 로컬 계약 테스트는 생성한 URL·브라우저 동작만 검증함.
